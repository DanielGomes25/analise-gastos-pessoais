# Análise de Gastos Pessoais

Projeto de análise de dados financeiros utilizando SQL e Python.

## Tecnologias
- Python
- SQL

## Uso

1. Importe o CSV para um banco SQLite executando `python3 importar_csv.py` ou `python3 consultas.sql`.
2. Execute consultas de várias maneiras:
   - num script Python separado (veja `consultas_sqlite.py` abaixo),
   - no notebook `notebook/analise.ipynb`,
   - ou com a CLI `sqlite3` se preferir.

### Exemplos

O arquivo `consultas_sqlite.py` contém exemplos de consultas que você pode editar e rodar.
